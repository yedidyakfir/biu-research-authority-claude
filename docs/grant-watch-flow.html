Why this is efficient

For the supplied seed, 41 old call rows map to 39 distinct funder URLs. The routine check is HTTP and database work; model tokens are spent only on changed or uncertain evidence. Old 2019–2025 deadlines are never rolled into a new year.

What coverage means

Accessible sources checked daily can normally surface a published change by the next completed run. No known URL list guarantees every new grant: blocked pages, unlisted programs, and missed jobs need explicit fallback checks. The digest reports these gaps instead of claiming full coverage.

Current scope: the monitoring and setup skills are prepared; no recurring job or outbound message channel has been connected yet. The pilot fetched three sample funder URLs: one redirected, one lacked HTTP cache validators, and one returned 403.
