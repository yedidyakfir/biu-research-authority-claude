# Financial Report plugin

This plugin contains `/financial-report:fund-report-analysis`. It reads an Excel ledger, preserves an untouched source copy, records proposed classifications in JSON, and creates a self-contained HTML review page. Reviewers can correct uncertain rows and export a new Excel workbook.

Install from the private marketplace after adding it: `/plugin install financial-report --marketplace yedidyakfir/biu-research-authority-claude`.

Foundation policy lives in `skills/fund-report-analysis/references/foundations/`. The first reference covers the Israel Science Foundation personal-grant budget headings. Those headings are a provisional taxonomy until the grant track, award year, approved budget, and written exceptions are known.
